# 🧬 DNA Sequence Analyzer

A Python-based bioinformatics project for analyzing DNA sequences.

## 📌 Project Overview

The DNA Sequence Analyzer is a beginner-friendly bioinformatics tool developed using Python.

It takes a DNA sequence as input and performs basic sequence analysis such as nucleotide counting, GC/AT content calculation, complementary sequence generation, and codon detection.

## ✨ Features

- DNA sequence validation
- DNA sequence length calculation
- A, T, G, C nucleotide counting
- GC content calculation
- AT content calculation
- Complementary DNA sequence
- Reverse complementary DNA sequence
- Start codon (ATG) detection
- Stop codon detection (TAA, TAG, TGA)
